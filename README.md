# Block 3 病理 Micro 跑台測驗

醫四上第二次病理 Micro（陳漢和）跑台練習網頁：43 片教學片，加上挑戰版 155 題（NUS Pathweb、ExpertPath、EBM 線上玻片、PathologyOutlines、PathPresenter 2 份簡報、老師複習課 EX 2 片盒）。作答後自動判分，看答案時可以打開整段共筆原頁和歷屆考古答案（B07–B11）。

43 片在範圍選單分成四類，範圍選單的「全部 30 片」只出今年第二次範圍（01–31，不含 02），02、32–43 要選自己的分類才會出：

- 01–31（02 除外）：今年第二次範圍，照老師 Section review (2.1) 10/28、(2.2) 11/11 的 31 片扣掉 02。115-1 Lab Orientation 考試範圍(二) 的片，加上 B11 共筆有的 PA0336 Lymphangioma，以及 29–31 三片胃腸 Epithelial tumor（Lab Orientation 漏列；10/28 老師說移到第二次考前教完，還是可以考）。
- 02、32–34：第二次範圍外（歷屆考過／指定加入）。02 PA0284 Chronic rejection, kidney 雖在 Lab Orientation 清單，但老師上課沒放（B12 Micro vol.5 封面標灰、p.80 寫先 pass）。32–34 是今年排在第三次、但歷屆考在第二次 Micro 的三片，答案照 B11 共筆。
- 35–36：課表外（B08 考過・共筆沒有答案）。今年課表沒有、B08 考在第二次 Micro 的兩片；共筆沒有答案表，只判器官和診斷，描述不計分。
- 37–43：舊範圍（第一次範圍，最多 2 題）。老師說每次考試最多 2 題考過去的範圍，這 7 片是第一次範圍裡最可能再出的。

02、32–43 每片看答案後的說明會寫它為什麼放進來、答案照哪一本。範圍選單另有「猜題・超高／高／中／低／混合」，是依考古與老師複習課片盒估的出題機率分組，只是參考。

## 下載與使用

1. 到右邊的 **[Releases](https://github.com/hsiehtzuchi/block3-micro-quiz/releases/latest)**，下載 `Block3_Micro_Quiz.zip`（約 48 MB），解壓縮。
2. 用**電腦**的 Safari 或 Chrome，**直接打開下載下來的 `Block3_Micro_Quiz.html`**（雙擊檔案即可）。
   - 不要在 GitHub 網頁上預覽，也不要放到其他網站或用手機開：線上玻片會被瀏覽器擋掉。
   - 預設亮色，右上角的月亮圖示可以切成深色。
3. 「線上玻片」需要網路。開場是實體顯微鏡 40×，每次出題隨機換一個有組織的視野。送出或看答案後，題目區上方的「看共筆原頁」可以看這個疾病的整段共筆。
   - 作答畫面右上的「☆ 加星號」可以標記想再看的題，答對答錯都會留著。「星號」分頁看全部星號題，範圍選單的「只練星號題」只出這些題。錯題本只放答錯自動加入的題，答到過關會自動移出（以前手動加入錯題本的題，第一次開新版會搬進星號）。
4. 範圍選單的「純考古」只出考古考過的疾病＋器官：
   - 同器官同疾病・EBM 線上玻片（27 題）：考古考過的教學片，加上 EBM 線上玻片裡同病、同器官的題。
   - 同器官同疾病・挑戰版（35 題）：其他網站同病、同器官的題（同器官不同部位也算，例如冠狀動脈、主動脈算動脈，直腸算大腸）。
   - 不同器官同疾病（8 題）：考古換過器官的題；看答案後會附上考過這個器官的那幾題考古標準答案。
   - 只練錯題：上面幾種裡在錯題本的題。
5. 範圍選單最下面是「挑戰版」：
   - NUS Pathweb：在旁邊視窗開，訪客就能看。
   - ExpertPath：要有學校訂閱權限。Safari 直接顯示在題目區；Chrome 讀不到時按「↗ 旁邊視窗開啟」。
   - EBM 線上玻片：直接在題目區。
   - PathologyOutlines：原圖直接顯示在題目區，不用登入。
   - PathPresenter：在旁邊視窗開簡報，看題目寫的第幾片（不要按 ⓘ，會露答案）。共 2 份：Dermpath Case #30（1 片）、同學整理的「病理micro 2」（27 片）。
   - 老師複習課 EX 2 片盒：11 題。
6. 判分：診斷要照標準病名一字不差、拼對；寫兩個病名算錯。看答案後的「判分說明」有每片的細節。
7. 發現答案、判分、玻片或共筆頁有錯：按題目上方的「回報錯誤」，寫哪裡錯了再按送出，會打開這個專案的 GitHub 回報頁，題號和你的作答都已經填好（要登入 GitHub），截圖可以直接貼在那一頁，按 Submit new issue 就送出了。

作答紀錄只存在你自己的瀏覽器，和 Block 1 的紀錄分開。換新版本前，先到「成績紀錄」按匯出，下載新版後再匯入。

## 更新
