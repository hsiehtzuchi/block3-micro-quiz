# Block 3 病理 Micro 跑台測驗

醫四上第二次病理 Micro（陳漢和）跑台練習網頁：28 片教學片（115-1 Lab Orientation 考試範圍(二) 27 片，加上 B11 共筆有的 PA0336 Lymphangioma），加上挑戰版 119 題（NUS Pathweb、ExpertPath、EBM 線上玻片、PathologyOutlines、PathPresenter）。作答後自動判分，看答案時可以打開整段共筆原頁和歷屆考古答案。

## 下載與使用

1. 到右邊的 **[Releases](https://github.com/hsiehtzuchi/block3-micro-quiz/releases/latest)**，下載 `Block3_Micro_Quiz.zip`（約 30 MB），解壓縮。
2. 用**電腦**的 Safari 或 Chrome，**直接打開下載下來的 `Block3_Micro_Quiz.html`**（雙擊檔案即可）。
   - 不要在 GitHub 網頁上預覽，也不要放到其他網站或用手機開：線上玻片會被瀏覽器擋掉。
3. 「🔬 線上玻片」需要網路。開場是實體顯微鏡 40×，每次出題隨機換一個有組織的視野。送出或看答案後，題目區上方的「📖 看共筆原頁」可以看這個疾病的整段共筆。
4. 範圍選單的「📜 純考古」只出考古考過的疾病＋器官：
   - 同器官同疾病・EBM 線上玻片（12 題）：考古考過的教學片，加上 EBM 線上玻片裡同病、同器官的題。
   - 同器官同疾病・挑戰版（10 題）：其他網站同病、同器官的題。
   - 不同器官同疾病（5 題）：考古換過器官的題；看答案後會附上考過這個器官的那幾題考古標準答案。
   - 只練錯題：上面幾種裡在錯題本的題。
5. 範圍選單最下面是「🧩 挑戰版」：
   - NUS Pathweb：在旁邊視窗開，訪客就能看。
   - ExpertPath：要有學校訂閱權限。Safari 直接顯示在題目區；Chrome 讀不到時按「↗ 旁邊視窗開啟」。
   - EBM 線上玻片：直接在題目區。
   - PathologyOutlines：原圖直接顯示在題目區，不用登入。
   - PathPresenter：在旁邊視窗開簡報，看題目寫的第幾片（不要按 ⓘ，會露答案）。
6. 判分：診斷要照標準病名一字不差、拼對；寫兩個病名算錯。看答案後的「⚠️ 判分說明」有每片的細節。

作答紀錄只存在你自己的瀏覽器，和 Block 1 的紀錄分開。換新版本前，先到「成績紀錄」按匯出，下載新版後再匯入。

## 更新

有新版本時會放在 Releases，重新下載即可。頁面上方的標題寫著題數，可以用來確認是不是新版。

- 答案依整理者的筆記與課程共筆（以 B12 共筆為主，心血管 4 片的 B12 還沒出，暫用 B11），僅供自己複習；如有疑問，以上課內容為準。
- 共筆圖與玻片截圖取自課程共筆與台大 EBM 數位玻片平台，版權屬原作者與平台。
- 外部網站（NUS Pathweb、ExpertPath、EBM、PathologyOutlines、PathPresenter）的玻片和圖片都是連到原網站開啟，沒有存在檔案裡；出處在看答案後顯示。
